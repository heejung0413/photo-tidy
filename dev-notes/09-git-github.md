# Git과 GitHub

## 커밋 작성자와 푸시 계정은 다르다

이 프로젝트에서 실제로 헷갈린 부분입니다.

| | 무엇 | 어디서 정하나 |
| --- | --- | --- |
| **커밋 작성자** | 커밋에 적히는 이름·이메일 | `git config user.name / user.email` |
| **푸시 계정** | GitHub에 올릴 때 로그인한 계정 | `gh auth`, SSH 키, 토큰 |

편지에 비유하면 작성자는 **편지 안에 쓴 이름**, 푸시 계정은 **우체국에 가져간 사람**입니다. 둘은 서로 확인하지 않습니다.

그래서 `heejung0413` 계정으로 푸시했는데 커밋에는 `ni-heejung`이 찍혀 있었습니다. 맥 전체 설정(전역)이 `ni-heejung`이었기 때문입니다.

### 설정의 범위

```bash
git config --global user.name "..."    # 이 맥의 모든 저장소
git config user.name "..."             # 이 저장소만 (전역보다 우선)
```

저장소마다 다른 계정을 쓰려면 저장소별 설정을 합니다. **새 저장소를 만들면 첫 커밋 전에 확인**하는 습관이 좋습니다.

### GitHub의 비공개 이메일

커밋의 이메일은 누구나 볼 수 있습니다. GitHub는 노출용 주소(`숫자+아이디@users.noreply.github.com`)를 제공하고, 이걸 쓰면 실제 메일을 숨기면서 프로필과 연결됩니다.

### 푸시 계정은 어떻게 정해지나

HTTPS 주소(`https://github.com/...`)로 푸시할 때, git은 **인증 도우미**(credential helper)에게 "아이디와 비밀번호(토큰)를 달라"고 묻습니다. 이 맥에서는 GitHub 명령줄 도구(`gh`)가 도우미이고, **지금 활성화된 계정**의 토큰을 줍니다.

그래서 활성 계정이 회사 계정이면, 개인 계정의 비공개 저장소에 푸시할 때 "Repository not found"가 납니다. 권한이 없는 비공개 저장소는 GitHub가 "없다"고 답하기 때문입니다(있는지조차 알려 주지 않으려는 것).

이 프로젝트는 저장소 설정에 "이 저장소는 `heejung0413` 계정의 토큰을 써라"를 넣어 해결했습니다. 터미널이든 Fork 같은 앱이든 같은 git 설정을 읽기 때문에 둘 다 적용됩니다.

## 커밋은 고칠 수 없다 — 새로 만들 뿐

커밋의 ID(`3f88da8` 같은 것)는 내용·작성자·시각·부모 커밋으로 계산한 값입니다. 하나라도 바뀌면 **다른 커밋**이 됩니다.

그래서 "과거 커밋의 작성자를 바꾼다"는 것은 실제로는 **그 커밋과 그 뒤의 모든 커밋을 새로 만드는 것**입니다.

## 강제 푸시

이미 GitHub에 올린 커밋을 새로 만들면, GitHub의 이력과 내 이력이 달라집니다. 이때 "내 것으로 덮어써라"가 강제 푸시(`git push --force`)입니다.

- 혼자 쓰는 저장소: 문제없지만 실수하면 되돌리기 번거롭습니다. 하기 전에 **백업 브랜치**를 만들어 둡니다.
- 여럿이 쓰는 저장소: 다른 사람의 작업을 날릴 수 있어 원칙적으로 금지입니다.

"되돌리기 어려운 일은 하기 전에 확인한다"가 기본입니다.

## 커밋 단위

한 커밋에는 **한 가지 일**을 담습니다. 이 프로젝트의 최근 이력입니다.

```
테스트 추가: 앱 계산을 Core로 옮겨 검증 (40 → 74개)
캡처 전체 갱신, 앱 기본 언어를 한국어로
docs: README 정리 (기능별 소개, 표, 알려진 한계)
UI 다듬기: 테마 색, 카드 모양, 홈·묶음·타임라인 화면 정리
```

나중에 "이 화면이 언제 왜 바뀌었지"를 찾을 때 제목만 보고 알 수 있어야 합니다.

## .gitignore

저장소에 올리지 않을 것을 적는 파일입니다. 이 프로젝트는 빌드 결과물(`build/`)과 생성되는 프로젝트 파일(`*.xcodeproj`)을 뺍니다.

원칙: **다시 만들 수 있는 것, 개인 설정, 비밀 값은 올리지 않는다.**

## 로컬과 원격

| 말 | 뜻 |
| --- | --- |
| 커밋 | 내 컴퓨터에 기록 |
| 푸시 | 그 기록을 GitHub에 올리기 |

커밋만 하고 푸시하지 않으면 GitHub에는 안 보입니다. 내 컴퓨터가 고장 나면 사라집니다.
