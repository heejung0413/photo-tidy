# 용어 사전

가나다·알파벳순이 아니라 주제별로 묶었습니다.

## 앱 개발

| 말 | 뜻 |
| --- | --- |
| 빌드 | 코드를 실행할 수 있는 앱으로 만드는 과정 |
| 컴파일 | 사람이 쓴 코드를 기계어로 번역하는 것. 빌드의 한 단계 |
| 시뮬레이터 | 맥에서 돌리는 가짜 아이폰 |
| 번들 ID | 앱의 고유 이름 (`com.heejung.phototidy`) |
| 코드 서명 | "누가 만든 앱인지" 확인 도장. 없으면 아이폰에 설치 불가 |
| 샌드박스 | 앱마다 따로 주어지는, 자기만 쓸 수 있는 저장 공간 |
| 프레임워크 | 애플이 미리 만들어 둔 기능 묶음 (Photos, MapKit 등) |
| 타깃 | 빌드 결과물 하나 (앱, 테스트 묶음) |
| 패키지 | 따로 떼어 재사용할 수 있는 코드 묶음 |

## Swift / SwiftUI

| 말 | 뜻 |
| --- | --- |
| 옵셔널 | 값이 없을 수도 있는 타입 (`String?`) |
| struct | 넘길 때 복사되는 데이터 타입 |
| class | 넘겨도 같은 것을 가리키는 타입 |
| enum | 정해진 경우 중 하나를 나타내는 타입 |
| 프로토콜 | "이런 걸 할 수 있다"는 약속 (TypeScript의 interface) |
| 클로저 | 이름 없는 함수 (JS의 화살표 함수) |
| extension | 이미 있는 타입에 기능 덧붙이기 |
| View | 화면 조각 (React 컴포넌트) |
| 수식어(modifier) | `.padding()`처럼 뷰에 붙이는 설정 |
| 바인딩(`$값`) | 값을 읽고 쓸 수 있는 연결 |

## 동시성

| 말 | 뜻 |
| --- | --- |
| 스레드 | 일하는 사람. 여러 명이 동시에 일할 수 있음 |
| 메인 스레드 | 화면 담당. 여기서 오래 걸리는 일을 하면 화면이 멈춤 |
| 백그라운드 | 화면 담당이 아닌 곳 |
| 경쟁 상태 | 두 작업이 같은 것을 동시에 건드려 결과가 꼬이는 문제 |
| 취소 | 진행 중인 작업에 "그만해" 신호를 보내는 것 |

## 데이터·알고리즘

| 말 | 뜻 |
| --- | --- |
| 캐시 | 한 번 구한 답을 저장해 두고 다시 쓰는 것 |
| 증분 처리 | 전체가 아니라 새로 생긴 것만 처리하는 것 |
| 임계값 | "이 값을 넘으면 A, 아니면 B"의 기준 숫자 |
| 매직 넘버 | 뜻 설명 없이 코드에 박힌 숫자. 피해야 함 |
| 시간 복잡도 | 데이터가 늘 때 걸리는 시간이 얼마나 늘어나는지 (O(n), O(n²)) |
| 순수 함수 | 같은 입력에 항상 같은 결과를 주고 바깥을 바꾸지 않는 함수 |
| 의존성 주입 | 필요한 것을 안에서 만들지 않고 밖에서 넣어 주는 것 |
| 역지오코딩 | 좌표를 장소 이름으로 바꾸는 것 |
| union-find | 서로 이어진 것끼리 무리로 모으는 방법 |

## 테스트

| 말 | 뜻 |
| --- | --- |
| 단위 테스트 | 함수 하나의 입력과 결과를 확인 |
| UI 테스트 | 앱을 실제로 띄워 조작하며 확인 |
| 경계값 | 기준 숫자 바로 그 값 (60초 기준이면 정확히 60초) |
| 변이 테스트 | 코드를 일부러 망가뜨려 테스트가 잡는지 확인 |
| 회귀 | 전에 되던 것이 고친 뒤 안 되는 것 |
| 접근성 라벨 | 버튼에 붙이는 이름. 화면 읽기 기능과 UI 테스트가 사용 |
