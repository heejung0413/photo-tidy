# 실제 아이폰에 설치

## 방법

1. `xcodegen generate` 후 `PhotoTidy.xcodeproj`를 Xcode로 연다.
2. Xcode 설정에 Apple 계정을 등록하고, 타깃의 Signing에서 Team을 고른다.
3. 아이폰을 연결하고 실행한다. 처음에는 아이폰 설정에서 개발자 앱을 신뢰해야 한다.

XcodeGen을 다시 돌리면 고른 Team이 지워진다. Team ID를 알게 되면 `project.yml`의 `DEVELOPMENT_TEAM`에 적는다(아직 안 적음).

## 유효 기간

| 방식 | 기간 | 비용 |
| --- | --- | --- |
| 무료 Apple 계정 | 7일마다 다시 설치 | 없음 |
| 유료 개발자 계정 | 1년 | 연 129,000원 |
| App Store / 비공개 링크 배포 | 만료 없음 | 유료 계정 + 심사 |

파일 하나를 받아 영구 설치하는 방법은 아이폰에 없다. 사용자는 **무료 계정으로 7일마다 재설치**하기로 했다(2026-11-16). 다시 설치해도 앱 데이터는 남는다.

## 상태

실제 기기 설치는 아직 안 했다(2026-11-16 기준). 설치 후 먼저 볼 것은 [known-issues](known-issues.md)의 "실제 기기에서 확인할 것".
