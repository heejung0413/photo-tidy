# 위키 운영 규칙

- **원본**: 코드, `docs/superpowers/specs/`(설계), `git log`. 위키는 원본을 요약·연결한 것이라, 어긋나면 원본이 맞다.
- **고칠 때**: 기능을 추가·변경하거나 결정이 바뀌면 관련 페이지를 고치고 [log](log.md)에 한 줄 추가한다. 새 페이지를 만들면 [index](index.md) 표에 넣는다.
- **쓰는 법**: 한 페이지에 한 주제. 사실은 확인한 것만 적고, 확인 못 한 것은 "미확인"이라고 적는다. 파일 경로와 함수 이름을 적어 찾을 수 있게 한다. 날짜는 절대 날짜(YYYY-MM-DD).
- **넣지 않는 것**: 코드 전체 복사, 커밋 목록, 사용자 개인 정보(이메일 등).
- `CLAUDE.md`는 "작업할 때 지킬 규칙", 위키는 "배경 지식". 같은 내용을 두 곳에 길게 쓰지 않는다.
