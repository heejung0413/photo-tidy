# 개요

## 무엇을 하는 앱인가

아이폰 사진첩을 대상으로 두 가지를 한다.

1. **정리**: 연달아 찍은 비슷한 사진을 묶고, 묶음마다 한 장을 추천한다. 사용자가 남길 사진을 확정하면 나머지를 지운다. → [cleanup](cleanup.md)
2. **타임라인**: 사진의 위치·시각으로 "머문 곳"을 만들어 지도와 목록으로 보여 준다. 하루씩 보거나 앨범(공유 앨범 포함) 하나를 통째로 본다. → [timeline](timeline.md)

사진은 기기 밖으로 나가지 않는다. 장소 이름을 받을 때 머문 곳 좌표만 애플 서버로 간다.

## 환경

- 아이폰 전용, Swift + SwiftUI, iOS 17 이상. Xcode 26.2, Swift 5 언어 모드.
- 개인 프로젝트. 저장소는 GitHub `heejung0413/photo-tidy`(비공개), 브랜치 `master`.
- 사용자는 프론트엔드 개발자이고 iOS·백엔드 경험이 없다. 설명은 쉬운 말과 비유로 한다.

## 용어

| 말 | 뜻 |
| --- | --- |
| 묶음 | 비슷하다고 판단한 사진 2장 이상 (`StoredGroup`) |
| 구간 | 촬영 간격 60초 이내로 이어진 사진들. 묶음은 구간 안에서만 만든다 |
| 지문 | Vision이 사진에서 뽑는 특징값. 두 지문의 거리가 가까우면 비슷한 사진 |
| 분석 기록 | 분석을 마친 사진 id 모음(`analyzedIDs`). 여기 없는 사진이 든 구간이 다음 분석 대상 |
| 머문 곳 | 가까운 곳(반경 200m)에서 이어 찍은 사진들 (`TimelineStop`) |
| 범위 | 타임라인에서 보는 대상: 전체 사진(하루씩) 또는 앨범 하나 (`TimelineModel.Source`) |
