# 화면

## 테마 (`PhotoTidy/Views/Theme.swift`)

- 강조색 `Theme.accent`(청록). 앱 루트에서 `.tint`로 전체 적용. 화면에 `.blue` 등을 직접 쓰지 않는다.
- `.card()`: 둥근 흰 카드 배경. 화면 배경은 `Theme.background`(시스템 회색).
- `NumberBadge`: 타임라인 순번 동그라미.
- 공유 이미지도 같은 색을 쓴다.
- 다크 모드는 시스템 색을 따라가게 했지만 눈으로 확인하지 않았다.

## 화면별

| 화면 | 구성 |
| --- | --- |
| 홈(`HomeView`) | 상태별 안내 카드 + 큰 버튼. 분석 후에는 묶음 수, 통계 타일 2개(지울 수 있는 사진, 확보 용량), "묶음 보기", "새 사진 분석" |
| 묶음 목록(`GroupListView`) | List. 추천 사진 썸네일 + 장수 배지 + 촬영 시각 |
| 묶음 상세(`GroupDetailView`) | 좌우로 넘기는 큰 사진, "추천"·"n / N" 배지, 남기기 토글, 썸네일 줄, 삭제·건너뛰기 |
| 타임라인(`TimelineView`) | 범위 메뉴, 공유 버튼, 날짜 줄 또는 앨범 정보, 지도, 머문 곳 카드 |

## 테스트가 기대는 글자·이름 (바꾸면 화면 테스트가 깨진다)

`분석 시작`, `새 사진 분석`, `비슷한 사진 묶음`으로 시작하는 글자, `묶음 보기`, 목록의 List 셀, `나머지`로 시작하는 버튼, `정리할 묶음이 없어요`, `사진 접근 허용`, `이전 날`, `다음 날`, `보기`(달력), `범위 선택`, `사진 크게 보기`, `장소 이름 바꾸기`, `저장`, `타임라인 공유`.
