# Photo Tidy 설계

작성일: 2026-11-16

## 목적

아이폰 사진첩에서 연달아 찍은 비슷한 사진을 자동으로 묶고, 묶음마다 잘 나온 한 장을 추천한 뒤, 사용자가 확정하면 나머지를 삭제한다. 개인용 앱이며 서버는 없다.

## 결정 사항

| 항목 | 결정 |
| --- | --- |
| 플랫폼 | 아이폰 전용, iOS 17 이상 |
| 기술 | Swift + SwiftUI, 애플 기본 프레임워크(Photos, Vision)만 사용. 외부 라이브러리 없음 |
| 묶는 기준 | 연달아 찍은 비슷한 사진(완전 중복 포함) |
| 남길 사진 | 앱이 한 장 추천, 사용자가 바꾸거나 확정 |
| 삭제 | 사용자가 버튼을 눌렀을 때만, iOS 기본 확인 창을 거쳐 실행 |
| 데이터 | 전부 기기 안에서 처리. 네트워크 요청 없음 |

## 1차 범위에서 제외

- 동영상, 라이브 포토의 영상 부분(라이브 포토는 정지 사진으로만 취급)
- iCloud에만 있는 원본 내려받기(기기에 있는 미리보기 크기 이미지로 분석)
- 스크린샷 분류, 앨범 분류
- 앱스토어 출시, 아이패드 화면

## 구조

화면과 로직을 분리한다. 로직은 화면 없이 단독으로 테스트할 수 있어야 한다.

```
PhotoTidy (앱)
├── 화면: HomeView, GroupListView, GroupDetailView
├── AppModel            화면 상태(권한, 진행률, 묶음 목록)를 들고 있는 단일 저장소
└── PhotoLibrary        사진첩 읽기/삭제 (Photos 프레임워크 래퍼)

PhotoTidyCore (로컬 Swift 패키지, 화면·사진첩 의존 없음)
├── SimilarityGrouper   사진 목록 → 묶음 목록
├── BestShotPicker      묶음 → 추천 사진
├── ImageAnalyzer       이미지 한 장 → 지문·품질 점수 (Vision 래퍼)
└── GroupStore          분석 결과 저장/불러오기
```

### 모듈별 역할

**PhotoLibrary**
- 권한 요청과 상태 확인(전체 허용 / 일부 허용 / 거부).
- 사진 목록 조회: 이미지 타입만, 촬영 시각 오름차순. 항목마다 `id`, 촬영 시각, 즐겨찾기 여부, 편집 여부, 픽셀 크기를 돌려준다.
- 분석용 이미지 요청: 긴 변 약 512px. 네트워크 접근은 끈다(iCloud 전용 사진은 기기에 있는 미리보기로 받고, 그것도 없으면 건너뛴다).
- 삭제 요청: `id` 목록을 받아 iOS 삭제 확인 창을 띄우고 성공/취소를 돌려준다.

**ImageAnalyzer**
- 이미지 한 장에서 다음을 계산한다.
  - 내용 지문: Vision의 이미지 feature print.
  - 선명도: 밝기 이미지에 라플라시안 필터를 적용한 값의 분산(클수록 선명).
  - 얼굴 품질: Vision 얼굴 캡처 품질 점수. 얼굴이 여러 개면 평균, 없으면 값 없음.

**SimilarityGrouper**
- 입력: 촬영 시각순 사진 목록과 각 사진의 지문.
- 1단계(시간 구간): 바로 앞 사진과의 촬영 간격이 60초 이내면 같은 구간으로 잇는다.
- 2단계(내용 비교): 구간 안에서 지문 거리가 임계값 이하인 사진끼리 연결하고, 연결된 덩어리를 묶음으로 만든다. 임계값 초기값은 0.5이며, 샘플 사진 테스트로 조정한다.
- 사진이 2장 이상인 묶음만 결과에 포함한다.
- 구간에 사진이 1장뿐이면 비교할 대상이 없으므로 이미지 분석 자체를 건너뛴다(속도를 위해).
- 시간 간격과 임계값은 상수 한 곳에 모아 둔다.

**BestShotPicker**
- 묶음 안 각 사진에 점수를 매겨 최고점 한 장을 추천한다.
- 즐겨찾기 사진이 있으면 그중에서만 고른다(즐겨찾기가 최우선).
- 묶음의 모든 사진에서 얼굴이 잡혔으면: 점수 = 선명도(묶음 안 0~1 정규화) × 0.5 + 얼굴 품질(0~1) × 0.4 + 편집 여부 × 0.1.
- 얼굴이 안 잡힌 사진이 한 장이라도 있으면 얼굴 항목을 빼고: 점수 = 선명도 × 0.9 + 편집 여부 × 0.1.
- 동점이면 해상도가 큰 쪽, 그래도 같으면 나중에 찍은 쪽.

**GroupStore**
- 묶음 목록(사진 정보·품질 점수, 추천 `id`, 숨김 여부)과 마지막으로 분석한 촬영 시각을 기기의 JSON 파일로 저장한다.
- 다음 실행 때 마지막 분석 시각 − 60초 이후의 사진만 새로 분석한다. 새 묶음이 기존 묶음과 사진을 공유하면 하나로 합치고 추천을 다시 고른다.
- 정리를 끝낸 묶음에 사진이 2장 이상 남으면 지우지 않고 숨김으로 표시한다(다음 분석에서 같은 묶음이 다시 나타나지 않게). 숨긴 묶음에 새 사진이 합쳐지면 다시 보인다.
- 알려진 한계: 마지막 분석 시각보다 촬영 시각이 오래된 사진이 나중에 추가되면(에어드롭 등) 분석 대상에서 빠진다.
- 불러올 때 사진첩에서 이미 사라진 사진은 묶음에서 빼고, 1장만 남은 묶음은 지운다.

**AppModel**
- 흐름을 조율한다: 권한 확인 → 사진 목록 → 분석(진행률 갱신) → 묶기 → 추천 → 저장.
- 분석은 백그라운드에서 돌리고, 취소할 수 있다.

## 화면

1. **홈**
   - 권한이 없으면 설명과 "사진 접근 허용" 버튼. 거부 상태면 설정 앱으로 가는 버튼.
   - "분석 시작" 버튼, 분석 중에는 진행률(처리한 장수/전체)과 "취소".
   - 결과 요약: 묶음 수, 정리 가능한 장수, 확보 가능한 용량(픽셀 수 × 0.2바이트로 어림). "묶음 보기"로 이동.
2. **묶음 목록**
   - 최신 묶음부터 나열. 각 줄에 대표 사진, 사진 수, 촬영 날짜.
   - 정리를 끝낸 묶음은 목록에서 사라진다.
3. **묶음 상세**
   - 큰 사진을 좌우로 넘겨 보고, 아래 썸네일 줄에서 "남길 사진"을 체크한다(여러 장 가능).
   - 앱 추천 사진에 "추천" 표시가 붙고 미리 체크돼 있다.
   - "나머지 N장 삭제" 버튼 → iOS 확인 창 → 성공 시 목록으로 돌아간다.
   - "이 묶음 건너뛰기": 삭제 없이 목록에서 숨긴다(다시 분석해도 같은 묶음은 숨김 유지).

## 데이터 흐름

```
사진첩 ──PhotoLibrary──▶ 사진 목록
                           │ (한 장씩 512px 이미지)
                           ▼
                     ImageAnalyzer ──▶ 지문·선명도·얼굴 품질
                           ▼
                   SimilarityGrouper ──▶ 묶음 목록
                           ▼
                    BestShotPicker ──▶ 묶음별 추천
                           ▼
                 GroupStore(저장) ──▶ AppModel ──▶ 화면
```

## 오류·예외 처리

| 상황 | 동작 |
| --- | --- |
| 권한 거부 | 홈에 안내와 설정 이동 버튼만 보여 준다 |
| 일부 사진만 허용 | 허용된 사진만 분석하고, 홈에 "일부 사진만 분석 중" 안내 |
| 이미지를 못 받는 사진 | 건너뛰고 계속 진행. 건너뛴 장수를 요약에 표시 |
| 분석 중 앱 종료·취소 | 그때까지의 결과를 저장하고, 다음에 이어서 분석 |
| 삭제 확인 창에서 취소 | 아무것도 바꾸지 않고 상세 화면 유지 |
| 묶음의 사진이 다른 앱에서 삭제됨 | 불러올 때 정리(GroupStore 규칙) |
| 남길 사진을 0장 체크 | 삭제 버튼 비활성화(묶음 전체 삭제 방지) |

## 테스트

- `PhotoTidyCore`는 맥에서 `swift test`로 돌린다(Vision은 맥에서도 동작).
- SimilarityGrouper: 가짜 지문(직접 만든 거리 값)으로 시간 구간 나누기, 연결 덩어리 만들기, 1장짜리 제외를 검증.
- BestShotPicker: 즐겨찾기 우선, 얼굴 없음 가중치, 동점 규칙을 검증.
- GroupStore: 저장 후 불러오기, 사라진 사진 정리, 이어서 분석할 시작 시각.
- ImageAnalyzer: 테스트 코드가 직접 그린 이미지(선명한 것/흐린 것, 비슷한 쌍/다른 쌍)로 선명도 대소와 지문 거리 대소를 검증.
- 화면과 실제 사진첩 삭제는 시뮬레이터와 실제 아이폰에서 손으로 확인한다.

## 설치

Xcode로 본인 아이폰에 직접 설치한다. 무료 애플 계정은 7일마다 재설치가 필요하고, 유료 개발자 계정이면 1년간 유지된다.
