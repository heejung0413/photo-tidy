# 앨범 타임라인 설계

작성일: 2026-11-16

## 목적

타임라인 탭에서 앨범(특히 친구와 쓰는 사진 앱의 공유 앨범)을 고르면, 그 앨범의 사진 전체를 날짜별로 이어 붙인 타임라인을 한 화면에 보여 준다. 하루씩 보는 기존 화면은 그대로 둔다.

## 화면

- 타임라인 탭 맨 위 제목 자리에 범위 선택 메뉴를 둔다. 항목은 "전체 사진 (하루씩)"(기본), "공유 앨범" 묶음, "내 앨범" 묶음. 사진이 없는 앨범은 목록에서 뺀다.
- 앨범을 골랐을 때
  - ◀ 날짜 ▶ 줄 대신 앨범 이름과 `기간 · N장`을 보여 준다.
  - 지도: 앨범 전체의 머문 곳을 번호 핀으로 찍고 순서대로 선으로 잇는다. 위치 있는 머문 곳이 하나도 없으면 지도 대신 안내 문구를 보여 준다.
  - 목록: 날짜 구분 줄 아래에 그날의 머문 곳. 번호는 앨범 전체에서 이어진다. 앨범이 여러 해에 걸치면 구분 줄에 연도를 적는다.
  - 머문 곳 제목 → 지도 이동, 썸네일 → 크게 보기는 하루 화면과 같다.

## 규칙

1. 앨범 사진을 기기 시간대의 날짜별로 나누고, 날마다 기존 머문 곳 규칙(200m)을 적용한다. 날이 바뀌면 같은 장소여도 새 머문 곳이다.
2. 누가 올린 사진인지 구분하지 않고 촬영 시각순으로 본다.
3. 장소 이름은 기존과 같이 좌표만 보내 순서대로 받아 온다.
4. 앨범 화면의 사진은 기기에 없으면 내려받아 보여 준다(공유 앨범 사진은 기기에 없을 수 있다). 하루 화면은 기존대로 내려받지 않는다.

## 구조

| 위치 | 이름 | 역할 |
| --- | --- | --- |
| Core | `TimelineBuilder.days` (+ `TimelineDay`) | 여러 날 사진 → 날짜별 머문 곳 |
| 앱 | `PhotoLibrary+Albums` (+ `PhotoAlbum`) | 앨범 목록(공유·일반), 앨범 안 사진 읽기 |
| 앱 | `TimelineModel` | 범위(`Source`) 선택, 날짜별 묶음 상태 |
| 앱 | `TimelineView` | 범위 메뉴, 앨범 화면 |

## 테스트

- `TimelineBuilder.days`: 빈 입력, 날짜별 분리, 정렬, 시간대.
- 시뮬레이터: 공유 앨범은 iCloud 로그인이 필요해 만들 수 없다. 디버그 빌드에서 `-sampleAlbum` 실행 인자를 주면 사진첩 전체를 담은 일반 앨범 "샘플 앨범"을 만들고, 스모크 테스트가 그 앨범을 골라 화면을 확인한다.

## 실제 기기에서 확인할 것

- 공유 앨범이 "공유 앨범" 묶음에 나오는지.
- 공유 앨범 사진에 위치 정보가 남아 있는지(올린 사람의 설정에 따라 빠질 수 있음). 없으면 지도 없이 시간순 목록만 나온다.
- 공유 앨범 사진의 썸네일·크게 보기가 뜨는지(애플이 줄여 둔 사본이라 화질이 원본보다 낮을 수 있음).

## 범위에서 제외

동영상, 올린 사람별 구분·필터, 앨범 여러 개 합쳐 보기, 댓글·좋아요 표시.
