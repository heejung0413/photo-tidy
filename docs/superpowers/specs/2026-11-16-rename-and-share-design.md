# 장소 이름 고치기 · 타임라인 이미지 공유 설계

작성일: 2026-11-16

## 장소 이름 직접 고치기

- 머문 곳 줄 오른쪽 연필 버튼 → 입력 창 → 저장. 비워 두고 저장하면 직접 붙인 이름을 지우고 자동 이름으로 돌아간다.
- 직접 붙인 이름은 자동 이름보다 먼저 쓰이고, 지도 핀·목록·공유 이미지에 모두 반영된다.
- 저장 키: 위치가 있으면 중심 좌표를 소수 셋째 자리로 반올림한 값(약 100m 칸) → 같은 곳에 다시 가면 이름이 따라온다. 위치가 없으면 그 머문 곳의 첫 사진 id → 그 머문 곳에만 붙는다.
- 기기의 `custom-place-names.json`에 저장한다(`TimelineModel`). 자동 이름 캐시(`place-names.json`)와 분리해 둔다.

## 타임라인 이미지 공유

- 타임라인 탭 오른쪽 위 공유 버튼 → 지금 보고 있는 타임라인(하루 또는 앨범)을 JPEG 한 장으로 만들어 시스템 공유 창을 연다.
- 이미지 구성: 제목(날짜 또는 앨범 이름)·사진 수, 지도(번호 핀, 경로 선은 날짜별로 끊음), 머문 곳마다 번호·이름·시각·썸네일 최대 4장(+N).
- 화면의 `Map`은 그림으로 못 뜨므로 `MKMapSnapshotter`로 지도 그림을 따로 받아 핀과 선을 직접 그린다. 지도를 못 받으면 지도 없이 만든다.
- 머문 곳은 최대 40곳까지 담고 넘으면 "외 N곳"으로 적는다(이미지 길이 제한).
- 구현: `TimelineShare`(앱). 파일은 임시 폴더 `타임라인.jpg`.

## 테스트

시뮬레이터 스모크 테스트 `testRenameStopAndShare`: 이름 바꾸기 → 화면 반영 확인 → 공유 창 표시 확인. 만들어진 이미지는 앱 컨테이너 `tmp/타임라인.jpg`에서 눈으로 확인한다.

## 범위에서 제외

이미지 꾸미기(테마·글꼴), 동영상·PDF 내보내기, 직접 붙인 이름의 기기 간 동기화.
