# 하루 타임라인 설계

작성일: 2026-11-16

## 목적

하루 동안 찍은 사진을 시간순으로 놓고, 가까운 곳에서 찍은 사진을 "머문 곳"으로 묶어 지도와 목록으로 보여 준다. 기존 정리 기능의 코드와 저장 데이터는 바꾸지 않는다.

## 화면

- 하단 탭 두 개: "정리"(기존 홈), "타임라인".
- 타임라인 탭
  - 날짜 줄: ◀ 날짜 ▶. 처음에는 사진이 있는 가장 최근 날. ◀ ▶ 는 사진이 있는 이전·다음 날로 이동. 날짜를 누르면 달력에서 고르고, 고른 날에 사진이 없으면 가장 가까운 사진 있는 날을 보여 준다.
  - 지도: 위치가 있는 머문 곳을 번호 핀으로 찍고 순서대로 선으로 잇는다. 위치 있는 머문 곳이 없으면 지도를 숨긴다.
  - 목록: 머문 곳마다 번호, 장소 이름, `시작–끝 시각 · N장`, 썸네일 줄.
  - 머문 곳 제목을 누르면 지도가 그 핀으로 이동한다. 썸네일을 누르면 사진을 크게 본다.
- 사진 접근 권한이 없으면 "정리 탭에서 허용해 주세요" 안내만 보여 준다.

## 머문 곳 규칙

1. 하루는 기기 시간대 기준 0시부터 24시 전까지.
2. 사진을 촬영 시각순으로 본다. 사진의 좌표가 현재 머문 곳 중심(위치 있는 사진 좌표의 평균)에서 200m 이내면 같은 머문 곳, 벗어나면 새 머문 곳을 시작한다.
3. 다른 곳에 다녀온 뒤 같은 장소로 돌아오면 별개의 머문 곳이다.
4. 위치가 없는 사진은 현재 머문 곳에 넣는다. 그날 앞부분 사진에 위치가 없으면 처음 나오는 위치 있는 사진과 같은 머문 곳이 된다.
5. 그날 사진 전부에 위치가 없으면 중심이 없는 머문 곳 하나가 된다.
6. 반경 200m는 `Tuning.stopRadius`로 조정한다.

## 장소 이름

- 머문 곳 중심 좌표를 `CLGeocoder`(애플 서버)로 이름으로 바꾼다. 사진은 보내지 않고 좌표만 전송된다.
- 이름은 관심 지점 → 동(subLocality) → 시·군·구(locality) → 기타 이름 순으로 처음 있는 값을 쓴다.
- 좌표를 소수 셋째 자리로 반올림한 키로 기기에 저장해 같은 곳은 다시 묻지 않는다.
- 실패하거나 아직 못 받았으면 "장소 N", 위치가 없는 머문 곳은 "위치 정보 없음"으로 표시한다.
- 요청은 한 번에 하나씩 순서대로 보낸다. 날짜를 바꾸면 남은 요청은 취소한다.

## 구조

| 위치 | 이름 | 역할 |
| --- | --- | --- |
| Core | `TimelineBuilder` (+ `Coordinate`, `TimelinePhoto`, `TimelineStop`) | 사진 목록 → 머문 곳 목록. 거리 계산 포함. 화면·사진첩·네트워크와 무관 |
| 앱 | `PhotoLibrary` 확장 | 특정 날의 사진(좌표 포함) 읽기, 사진이 있는 날짜 목록 읽기 |
| 앱 | `PlaceNamer` | 좌표 → 이름, 저장 |
| 앱 | `TimelineModel` | 날짜 선택, 머문 곳·이름 상태 |
| 앱 | `TimelineView` | 날짜 줄, 지도, 목록 |

## 테스트

- `TimelineBuilder`: 거리 계산, 반경 안/밖, 돌아온 장소 분리, 위치 없는 사진(중간·앞부분·전부), 빈 입력, 정렬.
- 시뮬레이터 스모크 테스트: 위치·시각이 든 샘플 사진(스크립트로 생성)을 넣고 탭 전환 → 샘플 날짜의 머문 곳 표시 확인.

## 범위에서 제외

동영상, 장소 이름 직접 수정, 공유·내보내기, 이동 수단 추정, 여러 날 묶어 보기.
